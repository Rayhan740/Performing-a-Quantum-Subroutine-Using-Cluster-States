# Performing a Quantum Subroutine Using Cluster States

This repository explores the theoretical and computational implementation of a two-qubit phase oracle using measurement-based quantum computing (MBQC) and cluster states, inspired by Walther et al. (2005).

Key Features:

1. Explicit phase-oracle formulation: Develops a mathematical description of a two-qubit phase oracle within the MBQC framework.

2. Cluster-state construction: Demonstrates the mathematical procedure for constructing cluster states with larger numbers of qubits.

3. Four marked states: Investigates phase-oracle implementations for all four computational basis states: (|00\rangle), (|01\rangle), (|10\rangle), and (|11\rangle).

4. PennyLane simulations: Uses PennyLane for quantum circuit simulations to examine the proposed implementations.

5. Potential algorithmic application: Explores the two-qubit phase oracle as a possible subroutine for quantum algorithms.

6. MBQC framework: Focuses on cluster-state configurations, measurement patterns, and the mathematical description of measurement-based operations.

Reference:

P. Walther, K. Resch, T. Rudolph, E. Schenck, H. Weinfurter, V. Vedral, M. Aspelmeyer, and A. Zeilinger, “Experimental One-Way Quantum Computing,” Nature, vol. 434, pp. 169–176, 2005.
