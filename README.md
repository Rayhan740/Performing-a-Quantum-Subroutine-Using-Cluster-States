# Performing a Quantum Subroutine Using Cluster States

This repository explores the theoretical and computational implementation of a two qubit phase oracle using measurement based quantum computing (MBQC) and cluster states, inspired by Walther et al. (2005). Using PennyLane for quantum circuit simulations, the work explicitly formulates the phase oracle, demonstrates the mathematical construction of larger cluster states, and investigates the oracle as a potential subroutine for quantum algorithms. All four computational basis states—|00⟩, |01⟩, |10⟩, and |11⟩ are considered as marked states through corresponding circuit simulations.
